# Local baseline · 2026-10-05

Full corpus, one measured attempt per case, macOS arm64 / CPython 3.13. Raw local output is in `results/baseline-2026-10-05/`. Portable measured summaries are in [baseline.json](baseline.json).

The implementation was the local filerepack working tree: commit `2d41e71e02cf1c1c208679087b96fbd05a8a3926` plus uncommitted code. This is not a released-version performance claim. The Python source hash was stable across the run.

| Outcome | Cases |
|---|---:|
| improved | 263 |
| preservation-failure | 1 |
| unchanged | 139 |

All 403 attempts completed; no missing-verifier skips or worker errors remained. The 14 rejection controls remained byte-identical. Corpus checksums matched after the run.

**One strict metadata failure:** `fonts-synthetic-woff2` decreased from 744 to 716 bytes, but filerepack/fontTools updated `head.modified` from the fixed 2020 fixture date to the run time. Other uncompressed table XML matched after excluding the calculated checksum. The fixture remains a failure under this suite's timestamp-preservation contract; the run exits 1 and those savings are excluded.

This finding concerns the embedded font modification timestamp; it does not show a changed glyph outline. It is recorded explicitly rather than waived by the oracle.

## Size observations

| Verified subset | Cases | Input bytes | Output bytes | Byte-weighted savings |
|---|---:|---:|---:|---:|
| Native/original/syntax (excludes aliases and generic transports) | 233 | 26,783,973 | 10,378,487 | 61.25% |
| All verified non-control cases | 388 | 67,586,120 | 22,415,384 | 66.83% |
| Upstream originals, excluding rejection controls | 45 | 3,045,888 | 3,001,344 | 1.46% |

Synthetic files deliberately include redundant values, weak compression and database free space. Their large savings must not be extrapolated to typical production files. Thirteen original files improved and 35 original files remained unchanged, including the original safety controls.

RAR/CBR files generated by RAR 7.12 use methods unavailable in the installed 7zz reader. The independent unrar oracle reads them, and filerepack retained them unchanged. Several other formats remain unchanged because an optimizer is absent, a profile is unsupported/experimental, or a candidate is not smaller. Reasons and the tool/version inventory are in the full JSON report.

## Harness and smoke validation

- 21 harness regression tests passed; Ruff passed.
- Independent preflight decoded all 389 non-control fixtures, with zero failures or dependency skips.
- A separate smoke run used one discarded warmup and three measured attempts for each of 12 cases. All 36 measured attempts produced verified smaller outputs.
- The baseline used all 94 named packer/archive handler groups represented in the corpus; that describes coverage, not successful optimization by every handler.

No statistically stable full-corpus timing claim is made from one attempt. Use `--repeat 3 --warmup 1` on a quiet machine for comparisons.
